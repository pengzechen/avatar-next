# 系统调用实现文档

本文档描述了 Avatar OS 中实现的系统调用。

## 已实现的系统调用

### 进程管理

#### SYS_EXIT (0)
**功能**: 退出当前进程
**参数**: `status` (x0) - 退出状态码
**返回值**: 无
**状态**: ✅ 完整实现

#### SYS_YIELD (1)
**功能**: 让出 CPU
**参数**: 无
**返回值**: 0 表示成功
**状态**: ✅ 完整实现

#### SYS_GETPID (2)
**功能**: 获取当前进程 ID
**参数**: 无
**返回值**: 进程 ID
**状态**: ✅ 完整实现

#### SYS_SLEEP (3)
**功能**: 睡眠指定毫秒数
**参数**: `ms` (x0) - 毫秒数
**返回值**: 0 表示成功
**状态**: ⚠️ 简单实现（忙等待）
**TODO**: 改进为基于定时器的睡眠

### 内存管理

#### SYS_BRK (10)
**功能**: 设置程序断点
**参数**: `addr` (x0) - 新的程序断点地址
**返回值**: 新的程序断点，失败返回 (void*)-1
**状态**: ⚠️ 占位实现
**TODO**: 实现真正的堆管理器

#### SYS_SBRK (11)
**功能**: 增加程序断点
**参数**: `increment` (x0) - 增量的字节数
**返回值**: 旧的程序断点
**状态**: ⚠️ 简单实现（固定地址）

### 文件操作

#### SYS_WRITE (20)
**功能**: 输出字符串到设备
**参数**:
- `str` (x0) - 字符串指针
- `len` (x1) - 字符串长度
**返回值**: 实际写入的字符数
**状态**: ✅ 完整实现（输出到 UART）

#### SYS_READ (21)
**功能**: 从输入设备读取
**参数**:
- `buf` (x0) - 缓冲区指针
- `len` (x1) - 缓冲区大小
**返回值**: 实际读取的字符数
**状态**: ⚠️ 占位实现（总是返回 0）
**TODO**: 实现真正的输入缓冲

**参数**:
- `pathname` (x0) - 文件路径
- `flags` (x1) - 打开标志
- `mode` (x2) - 权限模式
**返回值**: 文件描述符，失败返回 -1

**参数**: `fd` (x0) - 文件描述符
**返回值**: 0 表示成功，失败返回 -1

## 用户空间接口

### 头文件
`include/unistd.h` - 提供用户空间系统调用的 C 语言声明

### 汇编包装
`lib/syscall.S` - 提供系统调用的汇编包装函数

### 使用示例

```c
#include "unistd.h"

void example(void) {
    int64_t pid;

    /* 获取进程 ID */
    pid = getpid();

    /* 输出字符串 */
    write("Hello\n", 6);

    /* 睡眠 100 毫秒 */
    sleep(100);

    /* 让出 CPU */
    __asm__ volatile (
        "mov x8, #1 \n"
        "svc #0"
    );

    /* 退出进程 */
    exit(0);
}
```

## 系统调用约定（AArch64）

- **系统调用号**: x8 寄存器
- **参数**: x0-x5 寄存器（最多 6 个参数）
- **返回值**: x0 寄存器
- **触发方式**: `svc #0` 指令

## 内核实现

### 文件
- `kernel/syscall/syscall.h` - 系统调用接口定义
- `kernel/syscall/syscall.c` - 系统调用实现

### 分发器
`syscall_handler()` 函数负责根据 x8 中的系统调用号分发到具体的处理函数。
